# DesignVault

Run `npx designvault` in any project to visually browse your AI-generated designs.

![DesignVault screenshot](https://raw.githubusercontent.com/khushh7/designvault/main/screenshot.png)

## Install

```bash
npx designvault
```

Or install globally:

```bash
npm i -g designvault
designvault
```

## What it does

DesignVault scans your project for HTML, JSX, TSX, and SVG files and opens a visual gallery in your browser. Built for designers working with Claude Code, Cursor, and Codex.

- Visual previews of every design file
- Version stacking — groups iterations automatically
- Favorites, tags, notes, and status tracking
- Open any file in Claude Code, Codex, or Cursor
- Real-time updates as you design
- Works with any project, zero config
